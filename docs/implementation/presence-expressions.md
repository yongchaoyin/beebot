# Presence 表情与自然动作升级

## 范围与来源

本轮基于 `8491442ff6a751aa930175caf185eeffae32b98a`（PR #19），保留模型绑定、产品身份、原生窗口安全区、聊天密度、微信式引用及公开/内部消息边界修复。

参考项目 `sam70361/emotion-ball` 已迁到 `sam70361/aora-bot`。研究参考版本为 `e3b6148c818da4a8e1966f2bc89cdb3cee473b73`。当前仓库 `LICENSE`、`NOTICE.md` 与商业许可对代码、表情数据和球形形象分别设限。本次 **没有引入该项目的代码、轮廓点、眼形池、关键帧、图片、角色或 SDK**；也未新增包依赖或改变任何第三方许可证。借鉴的是参数化表情、平滑过渡、自然眨眼、角色适配和共享时钟的一般方法。本 PR 自行编写 64 单位画布上的三次曲线五官与动画参数。既有身体轮廓、11 色分类、持久化形状/颜色 ID 及其既有来源记录保持原状；本 PR 不宣称对既有第三方设计取得新权利。

不把“全部吸收”理解成把演示站搬入聊天：未采用持续撒花、彩带、红白闪烁、随机整圈自旋、自动巡演、自动情绪换色、输入正文分析，也未调用外部模型决定头像表情。

## 已实现

### 角色/表情/动效三层

- `avatar-art.ts` 继续负责身体、身份色和五官明暗；8 种形状、11 种颜色的选项、别名、自定义照片路径不变。
- 新 `avatar-expression.ts` 是纯数据与几何层，包含 16 种自主参数化表情：自然、关注、思考、阅读、检索、整理内容、执行工作、交接、回复、等待、等待确认、暂停、连接未知、异常、微笑、疑问。每只眼睛可分别调开合、弯曲、倾斜与高低，嘴部采用同拓扑三次曲线路径；没有以 CSS 翻转微笑冒充所有情绪。
- 三角、云朵、水滴、胶囊使用对应的五官安全范围；24–40px 放大少量眼部比例。身份主色不随表情、工作状态、浅深主题改变。
- `avatar-motion.ts` 保持既有共享控制器，增加可中断的表情形变、有限注视与一次性动作。过渡从当前姿态开始，不先闪回默认脸；采用解析阻尼响应按经过时间采样，而非固定每帧步长。
- 自然眨眼有不同闭合/停顿/睁开时长及少量双眨。节奏取自稳定身份与周期，不用同一个全局间隔让所有同事同时眨眼。调用方传入的身份必须在当前文档内唯一；跨节点渲染应继续沿用应用现有的带作用域身份，不能靠显示名称合并。
- 鼠标仅在显式允许跟随的预览等位置触发；缓慢转向、离开回正，最新位置取代积压位置。眼神与状态姿态由同一个合成器控制，不用多个动画争抢同一 transform。
- 身体/面部/注视/眼睛/嘴巴分组，保留原有 `sourceId` 与 `<use>` 镜像契约；固定 SVG 外部尺寸与边界，不挤动标题、消息或输入区。

### 真实状态投影，不制造工作

保留 `avatarStateFromAgent` 的优先级：连接未知/断线、错误、确认、等待、暂停等不被检索动画覆盖。只有已经运行的当前活动才细分阅读、检索、写作、执行和交接；历史活动、未知工具、模型 prose/JSON 不伪造工作。

- `WebSearch` / searching → 检索；`WebFetch` / reading / browsing → 阅读。
- writing / coding → 整理内容；running-commands → 执行工作；`SendToAgent` / sending → 交接。
- 真正在组织对外消息 → 回复；没有活动 → 自然。
- succeeded/cancelled 仍恢复自然，不由“停止运行”推断任务完成，更不为每次问答自动庆祝。

微笑、疑问、关注与轻庆祝可在预览使用。`celebrate()` 是可选的有限视觉接口，本轮**未新增完成回执订阅**，不宣称所有真实任务完成后都会自动庆祝。原有 spin/bounce/burst 兼容方法仍对应招呼/点头/确认，不恢复上游特效。任何预览/动作都不发送消息、创建工作、读取聊天正文、修改授权或写入 Bot 状态。

### 新建与设置都可预览

新建 Bot 继续用同一个 `mountAvatarPicker`，选形状与颜色仍按原流程保存；新增默认折叠的“试试表情和动作”，可选择 16 种表情，试招呼、点头、轻庆祝或还原。只有主预览动，选项缩略图静态。创建等待期间禁用控制，取消/卸载清理监听。

已有 Bot 的头像设置使用共享 `PresenceAvatarPreview`。可编辑 React 入口与固定版实际打包入口都使用同一 factory 和同一个 React 实例；没有第二套静态演示。语言切换只更新文案，不改形状/颜色或重建输入框。折叠/还原会立即取消未完的一次性笑眼；关闭预览不会改 Bot 的实际工作状态。

### 动效预算与生命周期

- 延续每文档一套协调器、一套可见性观察、稀疏时钟。只在姿态/注视/有限动作未稳定时启用共享 rAF，稳定即停止；没有每头像的永久逐帧 React 更新。
- 至多 2 个工作动态位；无工作动态时最多 1 个高优先级待机位；低动态/低资源模式最多 1 个工作位，仅保留小幅眨眼。同身份镜像只选最高优先级的位置。
- 历史头像、群拼图、引用缩略图按原 `paused` / `isStatic` 约定保持静态；小于 24px 不参与动态预算。
- 应用关闭动效、系统减少动态、窗口失焦、页面隐藏、离屏会取消动画并显示当前的静态表情。恢复时不补播积压动作；没有“用户没操作三分钟就让仍在运行的服务器 Bot 睡着”的计时器。
- 错误/暂停/等待确认是静态且可辨识的；辅助状态文字继续由原组件负责，SVG 本身 aria-hidden，不向屏幕阅读器逐帧播报。
- React 同时切换到历史静态头像和新状态时，旧控制器卸载不再把旧脸写回新 DOM。注册/状态同步在 layout effect 完成，避免首帧目标脸与旧脸闪动。

## 回归设计

新增 `tests/presence-expression.test.mjs`，覆盖实际活动和安全优先级、16 表情/8 形状/11 色有限几何、阻尼时间采样与中断、身份错峰及镜像预算、真实控制器生命周期、指针回正、草稿和焦点保持、离屏/失焦/减少动态/关闭动效、重置一次性动作、React 静态切换、创建预览不保存情绪以及固定版入口接线。

既有眼睛/嘴部对比度仍按 4.5:1 断言，只将嘴部测量从旧 stroke 改为实际填充路径的 fill。新建表单旧断言“没有 select”改为仅允许新增的折叠预览 select；19 个身份选择按钮和创建/错误/草稿断言保留。固定版 ASAR 重建测试继续执行，不放宽哈希锚点或删除旧验证。

本地精确 Node 26.5.0 + 当前 package-lock 依赖；Linux/macOS 构建结果见对应 PR，不能将以前提交的绿色检查替代本次结果。完整 Mac 运行时需要 bootstrap 的固定输入，本地 Linux 不冒充 Mac 安装验收。

浏览器使用 Playwright + Chromium（当前未提供 Browser 插件），内存加载本次编译的实际 Character、Preview、CreateBotSheet 与原始固定版 CSS/当前 Presence CSS；没有外部账户、模型、远端主机调用。检查中英/浅深色、1360px 与390px、16种表情、SVG 五官位于各身体轮廓内、有限庆祝恢复、创建后身份保存、40头像预算与静态终态。截图/录制展示的是受控夹具中的真实组件，不是用户已安装应用。

## 使用与未覆盖范围

重新构建并运行包含本 PR 的新版本，不需要重新建 Bot、删聊天、换 API 或清空 Keychain/数据卷。新增预览不增加持久化数据，不需要数据库迁移。没有修改头像照片、工作队列、引用、认证或模型解析。

没有发布安装包、Developer ID 签名或公证。浏览器和 CI 的原生窗口测试不等于用户旧配置升级、所有硬件/屏幕刷新率的性能与耗电验收；没有实测真实供应商响应驱动的长时间聊天。参考引擎的3D彩带、轮廓投影、32套受限数据与自定义脚本注册未导入；后续应按实际产品需要和许可另行评估，不将此 PR 宣称为第三方引擎的完整移植。
