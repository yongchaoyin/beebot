# 中性界面与动态头像

2026-09-22 · BeeBot 前端增量 · 替代历史 Honeyline 视觉方案。

## 范围与不变量

定位为简洁的办公与生活软件。当前用户可见表面使用中性灰白/深灰和克制的蓝色强调；移除旧主题叙事、昆虫造型和黄色主导。产品名仍是 BeeBot。六种原创圆润轮廓以形状、低饱和配色及细微表情区分身份；不复用厂商角色路径。自定义照片、群成员、账号、模型连接、发送顺序、未知送达恢复、权限判断及来源验证不因换肤改变。

## 单一实现

- `frontend/src/presence/tokens.css` / `presence.css`：语义主题，包括异常、排队、代码、焦点和输入态；旧 `--sand-*` / `--cursor-*` 变量仅为兼容别名。
- `avatar-art.ts`：六种几何路径、原始头像颜色与安全 DOM 适配。历史 `yellow` / `orange` 等配置键保留，但映射到新的中性颜色；旧形状映射到新的轮廓，不删除或批量改写用户数据。
- `avatar-state.ts`：纯函数将实际执行字段投影为 `idle/thinking/speaking/needs_user/waiting/paused/error/offline`；仅已知用户输入请求进入 `needs_user`，非空等待字符串不自动指派用户责任。
- `avatar-motion.ts`：每个文档一个协调器、一个可见性观察器、一个稀疏时钟。使用有限的 Web Animations API 动作；不使用 React 帧状态、持续 CSS 动画或每头像常驻计时器。
- `character.ts`：复用所在应用的 React 单例。源码、欢迎页、创建/编辑、正式打包头像接入同一工厂。SVG 和输入框在状态切换时保持稳定，不通过重挂载来播放动作。
- `motion-setting.ts`：「自然 / 轻微 / 关闭」，仅持久化本机展示偏好 `beebot.avatar-motion.v1`，不是 Agent 停止/继续指令；禁用存储时回退当前文档内存，不使聊天崩溃。

## 状态与动作

| 数据 | 表现 | 不做什么 |
| --- | --- | --- |
| 没有活动 | 主头像可低频眨眼、轻呼吸 | 不让侧栏所有头像轮流招手 |
| `isRunning` | 聚焦视线、间歇眨眼 | 不根据时间编造检索/完成进度 |
| `isComposingMessage` | 小幅点头、嘴部微动作 | 不模拟真实语音口型或推断情绪 |
| `awaitingUserResponse` | 稳定、睁眼的关注态 | 不闪烁红圈或摇晃窗口 |
| `waitingReason` | 静态等待 | 不将等待同事说成等待用户 |
| 暂停、错误、离线 | 可辨认的静态表情 | 不改变头像身份、不自动重试工作 |

文字状态来自同一投影，动效关闭时文字和责任状态不变。陈旧工具名称不能单独使空闲头像进入工作态。群聊/共享会话 ID 不用于伪造某位发言者身份；已知作者才补齐头像，未知作者保留现有消息表达。

## 动作预算与可访问性

自然模式最多两个可见工作头像同时获准动作，当前输出者优先；闲置时只允许一个主头像有间歇动作。轻微模式或低性能提示限制到一个工作头像，不播放待机呼吸。历史消息、静态群拼图、24px 以下头像不占用动作槽位。

眨眼约 190ms；回复点头约 560ms；工作视线约 1300ms；主头像待机呼吸约 1800ms。每次动作结束即释放，不持续占用动画对象。普通动作之间有间隔并错峰。指针跟随仅在头像附近、小幅度生效，不追踪整屏鼠标，不产生遥测。

系统 `prefers-reduced-motion`、页面隐藏、窗口失焦、离屏和用户关闭均停止动作。最后一个头像卸载时取消计时器、动画、观察器和全局监听；重新进入界面建立干净协调器。关注、等待和错误不靠动画作为唯一提示。交互控件保留键盘焦点和文字标签。

## 正式打包路径

仍使用经过认证的不可变上游渲染器作为输入，不移除来源哈希、CSP 或发布文件树校验。`scripts/lib/presence-renderer-patch.mjs` 对精确锚点/函数哈希失败关闭：共享 `sd` 头像、可见 `Iee` 显示分支、状态投影、形状/颜色选择器、欢迎页外层动效和应用图标路径。

原有隐藏源图不能承担可见性计时：可见头像现在直接渲染共享角色，旧的动作句柄按稳定身份转给可见实例。照片显示分支与群成员路由保留。欢迎页不再另套无穷浮动动画。编辑器使用同一角色和动效设置。应用图标从 `branding/beebot-app-icon.svg` 派生，正式 HTML 中的图标资源和 Dock 图标共用该来源。

`build-presence.mjs` 写入实际 `file://` 入口的样式与图标。发布校验从受信上游和当前源码重建，并逐文件比对 ASAR；只修改 manifest 或替换 CSS 仍被拒绝。历史证据、协议标识、原始安装包和许可证来源不作盲目字符串替换。

## 可重跑检查

执行 `npm run bootstrap` 后：

```sh
npm run typecheck
npm run source:typecheck
node --test tests/presence-*.test.mjs tests/app-icon.test.mjs
npm run frontend:build
npm run publication:check
```

常规 `npm run check` 包含新增状态/动作协调器回归与原有消息、引用和可靠性测试。打包测试使用真实固定上游文件，并校验自定义照片、可见头像、欢迎页动效归属、六种选择、共享状态、CSP 与篡改拒绝。原始 Mac 构建流程继续执行 `npm run icon:generate`。

浏览器验收使用真实 React 组件和从实际打包补丁提取的头像/编辑器函数、受控数据，不冒充真实模型端到端会话。检查状态切换、形状/颜色选择、动效开关、降低动效、窄窗口、输入和草稿连续性。完整安装后的窗口生命周期、真实远端网络、系统权限、语音、电脑画面、签名及更新仍需要交互式 Mac 环境；本增量不发布签名安装包，不自动合并主分支。
