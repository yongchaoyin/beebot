# 微信式引用：消息下方引用条与输入预览

基线：`2df001f398d0068f974ce7ef936b9e6538fca4c1`（PR #17）。保留模型绑定、品牌、窗口安全区、消息对比度和密度修复。本变更是聊天引用的展示和交互修正，不更换主题或头像系统，也不修改后端引用协议。

## 交互规则

发送后的结构是“回复正文气泡 → 气泡外的灰色引用条”。用户回复的引用靠右，Bot 回复的引用靠左，跟随**这条回复**而不是被引用者的身份。引用条只显示“作者：摘要”，取消旧的独立标题、强调色竖线和卡片式层级。

正文摘要为纯文本，最多两行，长内容省略；中文/英文沿现有语言设置，作者使用隔离文本方向。引用其他引用消息只显示直接原消息，不在气泡中递归嵌套整个讨论。直接 `reply_to` 与工作关联 `work_on` 继续独立，不能因样式调整改变 Agent 交接目标。

输入中的引用在编辑区下方显示为一条紧凑灰色预览，右侧“×”取消引用。取消只清除引用选择，不清正文、附件或富文本；鼠标操作阻止默认抢焦点，键盘可正常访问取消按钮。发送后引用随当前消息提交，不能泄漏到后续第二、第三条消息。

点击或键盘激活引用仍使用现有**当前会话**的定位/分页机制，不打开话题窗口或消息详情弹窗。不扩大权限、跨会话搜索或默认重放历史工作。找不到原文时显示“原消息暂不可用”，保留记录；异步明确成功时结束定位状态，不随后错误提示“不可用”。

图片引用优先使用正式渲染器**已经授权并解析完成的附件缓存**中的 raster data URL，显示 32px 缩略图（输入区 24px）；没有可用缓存就显示 `[图片]`，不直接请求消息内的 HTTP/file URL，不接受 SVG/HTML data URL。源码/远端路径没有同一缓存时同样保留安全的类型占位，不伪造缩略图。文件显示类型与文件名，链接只显示文本摘要，不主动加载外部预览。本轮没有新增语音/视频解码或局部文字引用协议。

## 实现路径

- `quoted-reply-ui.ts` 统一共享组件、可读灰色配对色、两行/单行摘要、图片缓存源校验与无弹窗导航状态。
- `presence/tokens.css` 和 `presence.css` 移除旧的强调色竖线及大标题覆盖，浅深色分别成对配置，正文与悬停态保持对比度。
- 可编辑 `ConversationTranscript` 把引用移到完整气泡/action anchor **之后**，并在 `send-message` 卡片路径显式保留引用。外层行、正文和工具交互结构不变；原成员名优先于笼统的 Agent 回退名。
- 可编辑 `ConversationComposer` 将预览放到现有富文本编辑器之后；不重建编辑器或替换草稿管理。
- 正式 `quoted-reply-patch.mjs` 对实际 `Roe` 子序列由 `[O,_]` 改为 `[_,O]`，保留原 reaction/thread 外层结构；根据原 `pGe(entry)` 标记回复侧。未覆盖原生虚拟滚动的定位、transform 或高度缓存。
- 正式输入区由 `[Vr,si,Yi,ri,ii,Gr,br]` 改为 `[Vr,si,Yi,null,ii,Gr,ri,br]`。保留编辑器 `Gr` 的子节点位置和原编译缓存依赖，避免增加/取消引用时重建正文。
- 正式 `pCn`、`uPn`、`Kvn` 复用同一共享实现和既有 `kAe` 缓存读取；显式文中引用仍为轻量行内引用，常规回复为气泡下方引用。
- 所有新增固定版锚点都要求准确命中一次；锚点漂移失败。原始归档、授权、CSP、来源哈希、资源重建、签名和发布检查不放宽。
